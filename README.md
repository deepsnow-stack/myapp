# 3D Minecraft Web MVP

ブラウザ上で動作する Three.js 製の 3D マインクラフト MVP です。
GitHub Pages で自動公開されています。

## 公開URL
[https://deepsnow-stack.github.io/myapp/](https://deepsnow-stack.github.io/myapp/)

## 機能一覧
- **3Dボクセルワールド生成**: 起伏のある地形、草地・土・石の地層、樹木生成
- **プロシージャル・ピクセルテクスチャ**: 草、土、石、原木、葉、木材、レンガ、ガラス、金ブロックのドット絵風テクスチャ
- **プレイヤー操作 (FPS視点)**:
  - `W` `A` `S` `D`: 移動
  - `Space`: ジャンプ（飛行時は上昇）
  - `Shift`: 下降（飛行時）
  - `F`: 飛行モード（クリエイティブ）とサバイバルモードの切替
  - `R`: ワールド再生成
- **ブロックの採掘 & 設置 (Mine & Craft)**:
  - `左クリック`: 照準先ブロックの破壊（パーティクル & サウンド効果）
  - `右クリック`: 照準先の面にブロック設置
  - `1` 〜 `9` または `マウスホイール`: ホットバーのブロック選択
- **Web Audio API 効果音合成**: 破壊音・設置音・ジャンプ音
- **物理 & 当たり判定**: 自由落下、重力、簡易AABB衝突判定
